# HEXMAG

## Описание проекта

**HEXMAG** - это учебный проект интернет-магазина, разработанный с использованием **HTML, CSS и JavaScript** без сторонних фреймворков.

Проект получает данные о товарах через **Fake Store API** и позволяет пользователю:

* просматривать каталог товаров;
* открывать страницу отдельного товара;
* добавлять товары в корзину;
* регистрироваться и входить в систему;
* сохранять корзину и данные пользователя в LocalStorage.

## Основные возможности

### Каталог товаров

* Загрузка товаров с Fake Store API.
* Отображение изображения, названия и цены.
* Переход на страницу товара.
* Быстрое добавление товара в корзину.

### Страница товара

* Вывод подробной информации.
* Добавление товара в корзину.
* Переход в каталог или корзину.

### Корзина

* Хранение товаров в LocalStorage.
* Подсчёт общей стоимости.
* Удаление товаров.
* Оформление заказа (демонстрационная функция).

### Авторизация

* Регистрация пользователя.
* Вход по email и паролю.
* Хранение данных пользователя в LocalStorage.
* Отображение имени пользователя в шапке сайта.

## API

Проект использует открытое API:

https://fakestoreapi.com

Получение списка товаров:

```
GET /products
```

Получение товара по ID:

```
GET /products/{id}
```
